Choudhary-mart ek full-stack, responsive e-commerce web app hai jahan users products browse, cart me add aur secure checkout kar sakte hain.

**Live Demo:** [https://choudhary-mart.vercel.app](https://choudhary-mart.vercel.app) 

### ✨ Features
- 🔐 User Authentication (JWT + bcrypt)
- 🛍️ Product Listing with Search & Filters
- 🛒 Cart & Wishlist Functionality
- 💳 Secure Checkout (Razorpay / COD)
- 📱 100% Responsive & PWA Ready - Phone me app jaisa install hota hai
- ⚡ Lightning Fast (Vite + Lazy Loading)
- 👑 Admin Panel - Product Add/Edit/Delete

### 🛠️ Tech Stack
**Frontend:** React.js (Vite), Tailwind CSS, Redux Toolkit, React Router
**Backend:** Node.js, Express.js
**Database:** MongoDB Atlas
**Deployment:** Vercel (Frontend), Render (Backend)
